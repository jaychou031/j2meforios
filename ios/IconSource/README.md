# App icon source

Selected by the user from:
https://github.com/HelloClyde/BBK9588-J2ME/tree/main/assets/icons

Original asset: `j2me-coffee.png` (512 x 512, transparent PNG), downloaded
and supplied by the user. The green-background `j2me-coffee-source.png`
was not used. The artwork itself is retained; generated iPhone icons
composite it on white and resize it. iOS applies the final corner mask.

Regenerate with `python scripts/make-app-icons.py` (Pillow required locally).
Generated PNGs and the asset catalog are committed, so no image download or
Pillow installation is needed during the GitHub Actions build.
